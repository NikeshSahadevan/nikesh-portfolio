# Nikesh Sahadevan – Full-Stack Portfolio Architecture

- **GitHub Repo:** `NikeshSahadevan/nikesh-portfolio`
- **Frontend:** React + Vite (`frontend/src/App.jsx`, `frontend/src/App.css`) hosted on **Vercel** (`https://nikesh-portfolio-five.vercel.app`)
- **Backend:** Python FastAPI (`backend/main.py`) hosted on **Render** (`https://nikesh-portfolio-api.onrender.com`)
- **Database:** **Neon PostgreSQL** (Tables: `projects`, `experiences`, `certifications`, `site_settings`, `messages`, `admin_users`)
- **Deployment Workflow:** Edit locally in VS Code -> `git add .` -> `git commit -m "..."` -> `git push` (Auto-deploys to Vercel & Render).
